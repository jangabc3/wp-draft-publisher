# 한국어 설치 안내

## 1. 준비하기

Windows에 Python 3.9 이상과 Codex가 설치되어 있어야 합니다. PowerShell에서 다음 명령으로 확인할 수 있습니다.

```powershell
python --version
```

WordPress는 HTTPS 주소여야 하며 REST API가 차단되지 않아야 합니다.

## 2. WordPress 전용 사용자 만들기

WordPress 관리자에서 **사용자 → 새로 추가**로 이동합니다. 개인 관리자 계정 대신 글 작성과 미디어 업로드에 필요한 권한만 가진 전용 사용자를 만드는 것을 권장합니다.

만든 사용자의 프로필을 열고 **애플리케이션 비밀번호**에서 `WP Draft Publisher`라는 이름으로 새 비밀번호를 발급합니다. 화면에 한 번 표시되는 비밀번호를 설치 과정에서 입력합니다.

## 3. 프로그램 설치하기

1. GitHub Releases에서 `wp-draft-publisher-v1.0.3.zip`을 내려받습니다.
2. ZIP의 압축을 풉니다.
3. 폴더 안의 `install.cmd`를 두 번 클릭합니다.
4. WordPress 주소는 `https://example.com`처럼 입력합니다.
5. 전용 사용자의 이름과 애플리케이션 비밀번호를 입력합니다. 비밀번호 입력 내용은 화면에 표시되지 않습니다.
6. 프로그램이 비밀번호를 저장하기 전에 인증, 글, 미디어, 카테고리, 태그와 브리지 접근을 읽기 전용으로 검사합니다.
7. 감지된 사이트 언어, 카테고리 수, SEO 플러그인과 브리지 버전을 확인합니다.
8. 사이트 이름, 독자층, 말투, 글 길이, 이미지 스타일, FAQ와 공식 출처 규칙을 입력합니다. 잘 모르겠다면 Enter를 눌러 추천값을 사용합니다.
9. Codex를 다시 시작하거나 새 채팅을 엽니다.

기존 설치가 있으면 삭제하지 않고 같은 폴더 옆에 백업한 후 새 버전을 설치합니다.

## 여러 사이트 추가하기

두 번째 사이트부터는 설치된 스킬 폴더의 `scripts\setup-credentials.ps1 -ProfileName "사이트별칭"`을 실행합니다. 이어서 `scripts\setup-profile.ps1 -Site "사이트별칭"`으로 해당 블로그의 말투와 카테고리를 설정합니다. `scripts\list-sites.ps1`은 비밀번호를 표시하지 않고 연결 목록과 기본 사이트만 보여줍니다.

명령 한 번에 사이트를 고를 때는 `scripts\run.ps1 --site 사이트별칭 doctor`처럼 입력합니다. Claude·Cursor용 MCP 연결은 환경 변수 `WPDP_SITE`에 사이트별칭을 넣어 세션 하나를 사이트 하나에 고정합니다. 이렇게 하면 AI가 요청 도중 다른 블로그로 바꾸지 않습니다.

## 4. WordPress 브리지 설치하기

GitHub Release에 함께 포함된 `draft-publisher-rest-bridge.zip`을 내려받습니다.

WordPress에서 **플러그인 → 새로 추가 → 플러그인 업로드**로 이동해 ZIP을 설치하고 활성화합니다. 이 플러그인은 동시 수정 방지, 복원 스냅샷, 작업 기록, SEO 플러그인 연동을 제공합니다.

활성화한 뒤 **도구 → Draft Publisher**에서 연결 준비 상태, 권한, 전용 사용자와 애플리케이션 비밀번호 안내, 최근 자동화 기록과 복원 지점을 확인할 수 있습니다.

## 5. 첫 글 시험하기

Codex 새 채팅에서 다음처럼 요청합니다.

```text
내 사이트 글쓰기 설정을 사용해서 전기요금 절약 방법을 최신 공식 자료로 조사하고 워드프레스 임시글로 저장해줘. 저장 후 제목과 이미지, SEO 정보가 정상인지 확인해줘.
```

WordPress **글 → 모든 글 → 임시글**에서 결과를 확인합니다. 자동으로 공개되지는 않습니다.

## 문제 해결

- `missing_credentials`: `scripts/setup-credentials.ps1`을 다시 실행합니다.
- `wordpress_http_401`: 사용자 이름과 애플리케이션 비밀번호를 다시 확인합니다.
- `wordpress_http_403`: 전용 사용자에게 글 작성과 미디어 업로드 권한이 있는지 확인합니다.
- `post_changed_since_read`: WordPress에서 최신 글을 확인한 뒤 다시 요청합니다.
- `seo_bridge_unavailable`: 브리지 플러그인을 설치·업데이트하거나 WordPress 기본 SEO 저장 방식을 사용합니다.

문제를 신고할 때 실제 비밀번호, 개인 사이트 주소, 글 전체 본문은 첨부하지 마세요.
