# Support

Use the GitHub issue templates for reproducible bugs and feature requests. Before filing a bug:

1. Run `scripts/run.ps1 doctor`.
2. Remove credentials, private URLs, and article contents from the output.
3. Record the project version, Windows version, Python version, WordPress version, and active SEO plugin.
4. Check whether the issue also occurs with `dry-run`.

Questions about WordPress hosting, themes, unrelated plugins, SEO strategy, or AI service billing are outside this project's support scope.

Security problems belong in a private vulnerability report as described in `SECURITY.md`.
